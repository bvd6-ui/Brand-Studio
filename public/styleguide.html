01 / Logo

An ending
left open.

An original geometric wordmark. The trailing line leaves space for what comes next. The same SVG appears in navigation.

Navigation size · 175px desktop / 150px narrow

Monochrome preview · one color

Custom path lettering keeps the silhouette stable without a font download. Every stroke uses one ink color, including the open-ended line; no grayscale filter is needed. Leave one letter-height of clear space when possible. Original design, not trademark clearance.

06 / Voice

Words are
design, too.

Curious, thoughtful, playful. Invite interpretation; keep size selection and demo feedback direct.

Curious, thoughtful, playful

“What will you write into today?”

Use open questions for storytelling. Use plain instructions for controls: “Choose a size.”

Useful, voluntary persuasion

Reciprocity: a free reading prompt offers value without signup. Liking: welcoming bookish language offers shared interests without claiming a customer community. No invented reviews, urgency, or authority.

A living reference. Change the shared tokens and logo, then compare this board with the storefront at the same width. Check the logo, typography, components, color roles, and voice text; sharing a stylesheet alone does not keep every example current. Save the reason for your choices in SPEC.
